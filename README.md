# DSA Assignment

This repository contains C programs for various DSA assignments completed as part of coursework.

## 📁 Repository Contents

Each folder named `prog_<number>` contains a separate C program that solves a specific problem or implements a specific algorithm.
And folder named `doc_<number>` contains documentation of the programs respectively.

Example folder structure:

doc_1.md   
prog_1.c   
prog_1.exe   

All programs are written in **C language**.

## 🧠 What’s Inside

- Implementation of different algorithms and data structures in C.
- Files follow a consistent naming convention (`prog_<num>`).
- Programs are designed for learning and assignment purposes.

## ▶️ How to Run the Programs

1. **Clone the repository**
   ```bash
   git clone https://github.com/Bijita02/dsa_assignment.git
     ```
2. **Navigate into a program folder**
   ```bash
   cd dsa_assignment/prog_1
    ```
3. **Compile the C program**
   ```bash
   gcc filename.c -o output
   ```
4. **Run the code**
   ```bash
   ./output
   ```
